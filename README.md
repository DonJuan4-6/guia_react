# Guía React

Repositorio con proyectos y guías de React.

## Proyectos incluidos

- **libreria_react**: Librería de componentes React
- **framework-react**: Framework React

## Instalación

Cada proyecto tiene sus propias dependencias. Navega a la carpeta específica e instala:

```bash
cd [nombre-proyecto]
npm install
```

## Desarrollo

Para iniciar el servidor de desarrollo:

```bash
npm run dev
```
